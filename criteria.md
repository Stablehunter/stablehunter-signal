# 筛选标准

Agentic Payment Signal 的核心不是“抓到所有新闻”，而是判断一条变化是否真的推动机器可执行支付的基础设施成形。

## 一条内容会被收录，如果它满足至少一项核心标准

### 1. Agent 可以发起或参与支付

包括：

- agent payment
- autonomous commerce
- machine-initiated transaction
- AI wallet
- delegated spending
- programmable authorization

判断问题：

- 这条变化是否让 AI agent 更接近真实支付行为？
- 它是否涉及授权、限额、风控、身份或执行？

### 2. 稳定币进入真实支付流程

包括：

- stablecoin checkout
- merchant settlement
- cross-border payout
- card issuing
- treasury flow
- on/off-ramp

判断问题：

- 它是否把 stablecoin 从交易场景推进到支付/结算场景？
- 它是否改变商户、平台、银行或用户的资金流？

### 3. 支付基础设施发生结构性变化

包括：

- payment API
- wallet infrastructure
- custody and policy engine
- bank rails
- card network integration
- real-time settlement

判断问题：

- 它是否改变 builder 接入支付能力的方式？
- 它是否让支付流程更可编程、更自动化或更可组合？

### 4. 身份、风控、合规支撑自动化支付

包括：

- KYC / KYB
- AML
- sanctions screening
- fraud detection
- identity orchestration
- transaction monitoring

判断问题：

- 它是否解决 agentic payment 里的信任、权限或风险问题？
- 它是否让自动化支付更容易被企业、银行或平台接受？

### 5. 高信号玩家明确表达方向变化

包括：

- Stripe、PayPal、Visa、Mastercard、Circle、Coinbase 等官方更新
- 高质量研究机构的长期 thesis
- 监管机构、银行或基础设施公司发布的新框架

判断问题：

- 这是否只是营销话术，还是带有产品、接口、合作、合规或商业落地信号？
- 它是否值得未来 3-12 个月持续观察？

## 降权或排除

以下内容通常不会进入日报，除非它们和支付基础设施有强关联：

- 只讲币价、TVL、短期交易情绪
- 只讲 AI 模型发布，但没有支付、钱包、风控或金融基础设施含义
- 只有二手转述，没有可核查原始来源
- airdrop、meme、KOL 喊单、泛 Web3 热点
- 只有“AI + crypto”口号，没有产品或接口细节

## 每条 signal 的最低质量要求

收录前尽量确认：

- 有原始来源链接
- 能用一句话说明“发生了什么”
- 能用一句话说明“为什么现在重要”
- 能说明适合谁看
- 不把推测写成事实

# Screening Criteria

The goal of Agentic Payment Signal is not to capture every piece of news. The goal is to decide whether a change helps machine-executable payments become real infrastructure.

## A Signal Can Be Included If It Matches At Least One Core Criterion

### 1. Agents Can Initiate or Participate in Payments

Examples:

- agent payment
- autonomous commerce
- machine-initiated transaction
- AI wallet
- delegated spending
- programmable authorization

Questions:

- Does this move AI agents closer to real payment behavior?
- Does it involve authorization, spending limits, risk, identity, or execution?

### 2. Stablecoins Enter Real Payment Workflows

Examples:

- stablecoin checkout
- merchant settlement
- cross-border payout
- card issuing
- treasury flow
- on/off-ramp

Questions:

- Does this move stablecoins from trading into payment or settlement workflows?
- Does it change money movement for merchants, platforms, banks, or users?

### 3. Payment Infrastructure Changes Structurally

Examples:

- payment APIs
- wallet infrastructure
- custody and policy engines
- bank rails
- card network integration
- real-time settlement

Questions:

- Does this change how builders access payment capabilities?
- Does it make payments more programmable, automated, or composable?

### 4. Identity, Risk, and Compliance Support Automated Payments

Examples:

- KYC / KYB
- AML
- sanctions screening
- fraud detection
- identity orchestration
- transaction monitoring

Questions:

- Does this solve a trust, permission, or risk problem in agentic payment?
- Does it make automated payments easier for enterprises, banks, or platforms to accept?

### 5. High-Signal Players Show Directional Change

Examples:

- Official updates from Stripe, PayPal, Visa, Mastercard, Circle, Coinbase, and similar players
- Long-term theses from high-quality research institutions
- New frameworks from regulators, banks, or infrastructure providers

Questions:

- Is this only marketing language, or does it include product, API, partnership, compliance, or commercial deployment signals?
- Is it worth watching over the next 3-12 months?

## Downrank or Exclude

The following items are usually excluded unless they have a strong payment infrastructure angle:

- Token price moves, TVL changes, or short-term trading sentiment
- AI model launches without payment, wallet, risk, or financial infrastructure implications
- Second-hand summaries without a verifiable primary source
- Airdrops, meme cycles, KOL calls, and generic Web3 trends
- Empty "AI + crypto" narratives without product or API details

## Minimum Quality Bar

Before inclusion, each signal should have:

- An original source link
- A one-sentence explanation of what changed
- A one-sentence explanation of why it matters now
- A clear audience
- Clear separation between fact and inference
