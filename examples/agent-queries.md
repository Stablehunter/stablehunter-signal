# Agent Query Examples

These are example queries for agents, research workflows, and internal bots using Agentic Payment Signal.

## Daily Brief

```text
Fetch the latest available Agentic Payment Daily Signal and turn it into a concise research brief.
Preserve source links and include the Stablehunter canonical URL.
```

## Founder View

```text
From the latest Agentic Payment Signal, identify the 3 updates a payment founder should read first.
Explain why each one matters for product, distribution, risk, or infrastructure strategy.
```

## Stablecoin Rails

```text
Review the past week of Agentic Payment Signals and summarize updates related to stablecoin rails, settlement, cards, treasury, or on/off-ramp infrastructure.
```

## Wallet / Risk / Compliance

```text
Find recent Agentic Payment Signals related to wallet permissions, identity, fraud, KYC, KYB, AML, compliance, auditability, or merchant trust.
Return the signal date, title, why it matters, and source URL.
```

## Internal Routing

```text
Turn today's Agentic Payment Signal into a five-line internal update for a product and BD team.
Do not add market claims beyond the source material.
```
